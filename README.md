# ✅ Todo App

A simple and responsive task management application built with HTML, CSS, and JavaScript. It allows users to organize daily tasks, manage their to-do lists, and save tasks locally using browser storage.

## 🚀 Live Demo

* **Live Website:** [View Todo App](https://satyamace.github.io/todo-app/)
* **GitHub Repository:** [View Source Code](https://github.com/Satyamace/todo-app)

## ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ☑️ Mark tasks as completed
* 💾 Persist tasks using localStorage
* 📱 Responsive design for desktop and mobile
* ⚡ Fast and lightweight interface

## 🛠️ Technologies Used

| Technology   | Purpose                           |
| ------------ | --------------------------------- |
| HTML5        | Application structure             |
| CSS3         | Styling and responsive layout     |
| JavaScript   | Task management and interactivity |
| localStorage | Persistent task storage           |
| GitHub Pages | Deployment                        |

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Satyamace/todo-app.git
```

### 2. Navigate to the project directory

```bash
cd todo-app
```

### 3. Run the application

Open `index.html` in your browser or use the VS Code Live Server extension.
